# Emotion Detector

An AI-based web application that detects emotions in customer feedback and text statements using IBM Watson NLP Emotion Prediction API and Flask.

## Features
- Analyzes text for five emotions: anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Deployed as a web application using Flask.
- Robust error handling for blank inputs (status code 400).
- Fully unit tested with Python's unittest module.
- 10.00/10 pylint code quality rating.
